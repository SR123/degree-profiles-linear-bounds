# Release metadata still requiring author choice

This is a curated local source packet for review and reproducibility. The author has not selected a redistribution licence for these project sources. No licence file or implied public-domain status has been added. Upstream Lean, Mathlib and dependency licences remain those of their respective projects; their sources/binaries are not bundled here.

A stable public repository or archival URL has not been created. The source and evidence can be exposed through the coordinated local reader/download, but that is not a claim of external publication, a DOI, journal acceptance or submission approval. Select the source licence, final hosting/archival metadata and any venue-specific disclosure requirements before external publication.

Public execution evidence consists of explicitly labelled derivatives with historical machine roots replaced by declared placeholders. Original/public hashes and exact provenance are recorded for each copy. Types, axiom reports, exit statuses and proof content are preserved. The unsanitised original records remain unchanged in the existing project archives and are not bundled in the public packet. Newly authored instructions and manifests use relative archive paths. Proof sources and pinned configuration remain byte-identical to their originals.
